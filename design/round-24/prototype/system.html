Extra is an outline chip, not a fill. It sits in the training-green family because it is training, but shape — not hue — keeps it distinct from an accent-soft surface and from the ink-filled current marker. UI state (“Now”, “Current”, “In progress”) never borrows a provenance chip's styling, or the provenance signal stops being a signal.

Session intensity and day resolution are two separate axes. Hue overlap between them is deliberate: they never appear in the same legend, and every badge on both axes carries an icon and a word, so no status is ever communicated by colour alone.
